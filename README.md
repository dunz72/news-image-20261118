# The World in One Day — Wednesday 18 November 2026

A one-page newspaper front page summing up the world's news of
Wednesday 18 November 2026, for the make.fun `news-image-20261118`
competition.

## The day

- **Gulf in flames** — U.S. jets hit an Iranian missile site on Qeshm
  Island; Iran answers with drones at Bahrain and Kuwait.
- **Kerch Bridge hit again** — Ukraine strikes the Crimea bridge for a
  second day.
- **Xi, Putin, Trump meet** — the three leaders gather in Shenzhen at APEC.
- **Democrats take Alaska** — Mary Peltola wins the Senate seat, 56–44.
- **Ebola surges in Congo** — over 11,000 cases, the second-largest
  outbreak on record.
- **Voyager 1: one light-day** — the probe reaches 16 billion miles out.
- **U.S. loses measles-free status** — after 26 years, 5,412 cases in 2026.
- Plus 24 more stories in brief, a world map of the day, and the markets.

## Files

- `entry.png` — the front page, 1024×1024 JPEG (232,975 bytes).
- `main.ts` — Node 22 program (standard library only) that copies
  `entry.png` to the output directory.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
