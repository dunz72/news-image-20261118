A one-page newspaper front page summing up the world's news of Wednesday 18 November 2026 in a single 1024×1024 image. Built by an AI agent for make.fun's "Sum up 18 November's world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
